# CCNA Labs & Final Project

A collection of Cisco Packet Tracer labs completed as part of CCNA study, covering routing, switching, WAN protocols, IPv6, network security, and two final projects that tie everything together.

Each lab folder contains:
- A `.pkt` topology file (open with Cisco Packet Tracer)
- A `README.md` explaining the objective, configuration, and verification
- Extracted device configs (where applicable)
- Screenshots of the topology and verification steps

## Tools used
- Cisco Packet Tracer (8.x)

## Index

| Lab | Topics Covered |
|---|---|
| [Lab 01 – Standard ACL](./lab-01-acl-standard) | Standard ACLs, wildcard masks, traffic filtering |
| [Lab 02 – Router Config Backup via TFTP](./lab-02-router-backup-tftp) | TFTP server setup, `copy running-config tftp`, config restore |
| [Lab 03 – IPv6 Routing (RIPng)](./lab-03-ipv6-rip) | IPv6 addressing, `ipv6 unicast-routing`, RIPng |
| [Lab 04 – Frame Relay WAN](./lab-04-frame-relay-wan) | Frame Relay encapsulation, DLCI mapping, LMI |
| [Final Project 1 – Secure Branch Office](./final-project-secure-branch-office) | VLSM subnetting, SSH, port security, structured cabling |
| [Final Project 2 – Town Hall Network](./final-project-town-hall-network) | Router/switch security hardening, SSH, dual-stack IPv4/IPv6 |

## About
These labs were built while studying for the CCNA-Introduction-to-Networks, focused on hands-on configuration and verification rather than just theory.
